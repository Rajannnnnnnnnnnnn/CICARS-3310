# CICARS 3310 — GitHub Pages: исправление чёрных экранов + ADMIN RESET

## Что исправлено

1. Удалено опасное восстановление `innerHTML` окон киноэффектов по Firebase: это удаляло JS-ссылки на элементы. Вместо этого передаётся только состояние, а у каждого участника остаётся свой DOM.
2. Отключено SVG-фильтрование с `<feImage data:>` для больших экранов: оно могло отрисовывать ЧЁРНУЮ поверхность при публикации на HTTPS. CSS теперь использует скругления, перспективу и виньетки без непрозрачного SVG-фильтра.
3. FINАL восстанавливает завершённый результат после перезагрузки страницы и при позднем подключении, а событие финальной анимации передаётся участникам.
4. Прямо на финальном экране есть **⚙ ADMIN / RESET**; пароль проверяется Firebase Authentication. После входа кнопка этапа **00** сбрасывает историю и прогресс у всей группы. Перед сбросом выводится подтверждение.
5. Включён Firebase-проект из присланной пользователем конфигурации; администратор указан в `firebase-config.js` и `firebase.rules.json`.
6. Встроен исправленный GitHub Actions workflow без рекурсивного копирования `_site`.

## Обновление сайта

1. В репозитории `CICARS-3310` замените существующие файлы файлами из этой папки. НЕ загружайте сам ZIP, а распакуйте его, и загрузите содержимое папки `CICARS_GITHUB_FIXED`.
2. Если GitHub Actions уже включён, проверьте Settings → Pages → Source: GitHub Actions.
3. Дождитесь Actions → Deploy CICARS to GitHub Pages → зелёная галочка.
4. Откройте страницу, нажмите Ctrl+Shift+R. Оба участника должны получить обновлённый интерфейс.
5. В Firebase Realtime Database → Rules используйте `firebase.rules.json` после проверки правильности UID администратора.

Если на хостинге остался старый чёрный экран, проверьте доступность `/styles.css`, `/app.js`, `/firebase-sync.js` в DevTools → Network; очистите кэш браузера.

## Оговорка
Тест с реальным Firebase RTDB и двумя браузерами требует доступа к вашему проекту; статический аудит/проверка JS не заменяют такой тест.
